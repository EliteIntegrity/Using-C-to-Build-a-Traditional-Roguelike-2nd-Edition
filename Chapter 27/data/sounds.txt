# The sounds of Amulets of SDL: which files each thing in the game plays,
# from the assets/sounds folder. When a sound has more than one file, one
# of them is chosen at random each time, so a hit doesn't sound the same
# every time. The game reads this file when it starts, so a change here
# needs no recompiling: save the file, and start the game again.
#
# Every [sound] record has these keys, in any order:
#   event   what makes the sound: one of the events below
#   files   its files, one or more, in assets/sounds
#
# The events:
# hit, kill, hurt, shoot, miss, lightning, fire, door_open, door_close,
# stairs, pick_up, gold, amulet, drop, wield, quiver, drink, read, heal,
# poisoned, confused, teleport, fear, trap, alarm, shriek, found, bump,
# breaks, refused, low_health, death, choose and win. An event left out
# makes no sound.
#
# A line starting with # is a comment, and blank lines don't matter. A
# mistake stops the game, and names the line it's on.
