# The vaults of Amulets of SDL: rooms made by hand. One in three floors has
# a treasure vault, built inside a room big enough to have floor all
# around it, or, in a cave, wherever its door opens onto the cave. The game
# reads this file when it starts, so a vault can be added here without
# recompiling: save the file, and start the game again.
#
# A record's keys:
#   id        its name: lowercase letters, digits and _
#   floors    the floors it can be on, from and to
#   amulet    yes for an Amulet's vault, one of which is on each of
#             floors 3, 6 and 9; leave it out for a treasure vault
#   guardian  the monster each G is, by its id: leave it out if there's
#             no G. The guardians wake together, as a pack
#   map       the vault, a row of cells to a line, each line starting
#             with a |:
#               #  wall          .  floor        +  door
#               S  secret door   ^  a trap       $  treasure
#               m  a monster from the floor's band
#               G  a guardian    A  the Amulet, in an Amulet's vault
#               (a space is outside the vault)
#
# A vault is from 3 x 3 to 15 x 9 cells, closed all around. Its one way in,
# a door or a secret door on its edge, reaches everything inside it.
#
# A line starting with # is a comment, and blank lines don't matter. A
# mistake stops the game, and names the line it's on.

[vault]
