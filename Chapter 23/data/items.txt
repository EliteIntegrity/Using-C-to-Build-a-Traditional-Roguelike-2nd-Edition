# The items of Amulets of SDL: one record for each kind. The record's type
# is the item's class: [potion], [scroll], [weapon], [armor], [bow],
# [missile], [gold] or [amulet]. The game reads this file when it starts,
# so a change here needs no recompiling: save the file, and start the game
# again.
#
# Every record has these keys, in any order:
#   id         its name in the data files: lowercase letters, digits and _
#   name       the kind's own name, as in "a potion of healing"
#   tile       its picture's name in assets/tiles.txt
#   frequency  how common it is: a kind with 10 is found twice as often as
#              one with 5, and one with 0 never
#
# And a record of each class has more:
#   [potion] and [scroll]:
#     effect   heal, heal_fully, strengthen, teleport, map_floor,
#              identify, poison, regenerate, confuse, frighten,
#              lightning or fireball, which the player aims
#   [weapon]:
#     damage   what each blow does, from and to, before strength and the
#              target's defense
#     thrown   yes if it's made to be thrown, as a dagger is; leave it out
#              for no
#   [armor]:
#     defense  taken off the damage of every blow the wearer takes
#     noisy    yes if walking in it makes a noise; leave it out for no
#   [bow]:
#     damage   what each arrow it fires does, from and to, before the
#              target's defense
#     range    how far it shoots, in cells
#   [missile]:
#     found    how many are found together, from and to
#     thrown   yes for a missile that's thrown, as a dart is; leave it out
#              for an arrow, which is fired from a bow
#     damage   for one that's thrown: what it does, from and to
#
# The game needs gold, which lies in piles of its own, and the amulet.
# Gold and the amulet are never chosen as items. There can be up to 10
# kinds of potion, one for each color.
#
# A line starting with # is a comment, and blank lines don't matter. A
# mistake stops the game, and names the line it's on.
