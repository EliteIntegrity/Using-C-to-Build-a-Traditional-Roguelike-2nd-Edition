# The monsters of Amulets of SDL: one [monster] record for each kind. The
# game reads this file when it starts, so a change here needs no
# recompiling: save the file, and start the game again.
#
# A record's keys can come in any order:
#   id       its name in the data files: lowercase letters, digits and _
#   name     its name in messages
#   glyph    its character in the glyph view
#   color    that character's red, green and blue, each from 0 to 255
#   tile     its picture's name in assets/tiles.txt
#   floors   the floors it's found on, from and to
#   hp       its health
#   damage   what each blow does, from and to, before the target's defense
#   defense  taken off the damage of every blow it takes
#   sight    how far it sees, in cells
#   traits   any of these, or leave the key out for none:
#              never_sleeps  erratic  stationary  shrieks  slow
#              never_flees   regenerates  drains  opens_doors
#              pack:N        found N at a time, all together
#              venomous:N    a hit poisons for N turns
#
# A line starting with # is a comment, and blank lines don't matter. A
# mistake stops the game, and names the line it's on.
